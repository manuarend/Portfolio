# 📊 Portfólio de Dados & Análise | Manuela Arend

Bem-vindo(a) ao meu repositório de portfólio de Análise de Dados e Business Intelligence!

Aqui compartilho projetos práticos desenvolvidos para resolver problemas de negócio, englobando modelagem de dados, análise exploratória (EDA), criação de métricas/KPIs e visualizações estratégicas.

---

## 🔒 Compromisso de Confidencialidade e Dados Sintéticos
> [!NOTE]
> Todos os conjuntos de dados utilizados nos projetos deste portfólio foram **100% sintetizados e anonimizados**:
> - **Valores e Métricas:** Os dados numéricos não guardam qualquer proporção ou relação com dados reais corporativos. Foram gerados em faixas abstratas e independentes para ilustrar a metodologia analítica.
> - **Nomes e Entidades:** Clientes, colaboradores e identificadores são fictícios.
> - **Geolocalização:** As análises têm como escopo geográfico dados simulados dos estados de **Espírito Santo (ES)**, **Rio de Janeiro (RJ)** e **São Paulo (SP)**.
