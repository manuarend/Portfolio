# 📊 Portfólio de Dados & Inteligência Comercial | Manuela Arend

Bem-vindo(a) ao meu portfólio profissional de **Análise de Dados, Business Intelligence e Inteligência Comercial**!

Aqui apresento quatro projetos práticos voltados à resolução de desafios reais do ambiente corporativo e industrial, abrangendo planejamento conjunto de negócios (**JBP**), acompanhamento de **campanhas digitais em filiais**, **inteligência de preços e competitividade**, e **scorecard de suprimentos e fornecedores**.

---

## 🔒 Compromisso de Confidencialidade e Dados Sintéticos
> [!NOTE]
> Todos os conjuntos de dados utilizados nos projetos deste portfólio foram **100% sintetizados e anonimizados**:
> - **Valores e Métricas:** Os dados numéricos não possuem qualquer relação, proporção ou espelhamento com dados reais corporativos, garantindo total conformidade com a LGPD e sigilo profissional.
> - **Escala dos Dados:** Quantidades foram delimitadas no intervalo de **1 a 50 unidades/lotes** e valores monetários entre **R$ 1.000,00 e R$ 10.000,00**.
> - **Nomes e Entidades:** Clientes, colaboradores e identificadores são fictícios. Nomes de indústrias consolidadas foram utilizados exclusivamente como contexto ilustrativo de mercado.
> - **Geolocalização:** As análises têm como escopo geográfico dados simulados dos polos industriais e comerciais de **Espírito Santo (ES)**, **Rio de Janeiro (RJ)** e **São Paulo (SP)**.

## 🚀 Como Explorar os Projetos Localmente
Cada projeto possui sua própria pasta contendo dados sintéticos prontos para uso em `data/` e rotinas executáveis em `scripts/`.

Para clonar e testar qualquer rotina:
```bash
git clone https://github.com/manuarend/Portfolio.git
cd Portfolio

# Exemplo: Executar o projeto 01 (JBP)
cd 01-jbp-joint-business-planning/scripts
python analise_jbp.py
```
